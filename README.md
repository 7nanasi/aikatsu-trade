# アイカツ！アンコール カード交換画像メーカー

カードを選んで「求」「譲」に振り分け、SNSにそのまま貼れる交換画像（PNG）を作れるツールです。
カードデータは [アイカツ！アンコール カードリスト](https://min-poke.github.io/cardlist-aikatsu-encore/) の `cards.js` をそのまま使用しています。

## 開き方

`index.html` をブラウザでダブルクリックして開くだけです。ネット接続が必要です（カード画像と画像生成ライブラリ html2canvas を外部から読み込むため）。

## 使い方

1. 弾・レアリティ・パラレル表示・検索・管理状態（所持／未所持／求／譲／交換予定）でカードを絞り込みます。レアリティは PR→ER→R→N の順で表示されます。
2. カードごとの「求」「譲」「予定」ボタンで状態を切り替えます（なし／求／譲／交換予定の4択・排他）。いずれかを押すとそのカードが登録され（もう一度押すと解除）、別のボタンを押すと切り替わります。状態のあるカードには枚数（＋／−）を指定できます。
3. カードごとに所持枚数（0／1／2／3+）を記録できます。求／譲／交換予定とは独立した項目で、未所持（0枚）のカードは画像が薄くグレーに表示されます。
4. 画面上部の「交換画像を作成」ボタンを押すと、「譲」が上・「求」が下に分かれたレイアウトの画像が1枚のPNGとしてダウンロードされます（交換予定のカードと所持枚数は画像に含まれません）。
5. 選択内容・所持枚数はブラウザに保存され、リロードしても消えません。「選択をすべてクリア」ボタンは誤操作防止のため、2回押すと確定します（所持枚数はクリアされません）。

## 注意

- 画像生成には [html2canvas](https://html2canvas.hertzen.com/)（CDN読み込み）を使用しています。オフライン環境では画像生成ができません。
- 共有URL機能はこのツールにはありません。
