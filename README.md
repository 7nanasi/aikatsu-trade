# アイカツ！アンコール カード交換画像メーカー

カードを選んで「求」「譲」に振り分け、SNSにそのまま貼れる交換画像（PNG）を作れるツールです。
カードデータは [アイカツ！アンコール カードリスト](https://min-poke.github.io/cardlist-aikatsu-encore/) の `cards.js` をそのまま使用しています。

## 開き方

`index.html` をブラウザでダブルクリックして開くだけです。ネット接続が必要です（カード画像と画像生成ライブラリ html2canvas を外部から読み込むため）。

## 使い方

1. 弾・レアリティ・パラレル表示・検索でカードを絞り込みます。
2. カードごとの「求」「譲」ボタンで状態を切り替えます。片方を押すとそのカードが登録され（もう一度押すと解除）、もう片方を押すと排他的に切り替わります。「求」「譲」になったカードには枚数（＋／−）を指定できます。
3. 画面上部の「交換画像を作成」ボタンを押すと、「譲」が上・「求」が下に分かれたレイアウトの画像が1枚のPNGとしてダウンロードされます。
4. 選択内容はブラウザに保存され、リロードしても消えません。「選択をすべてクリア」ボタンは誤操作防止のため、2回押すと確定します。

## 注意

- 画像生成には [html2canvas](https://html2canvas.hertzen.com/)（CDN読み込み）を使用しています。オフライン環境では画像生成ができません。
- 所持枚数管理機能・共有URL機能はこのツールにはありません。
