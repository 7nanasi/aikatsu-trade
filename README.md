# アイカツ！アンコール カード交換画像メーカー

カードを選んで「求」「譲」に振り分け、SNSにそのまま貼れる交換画像（PNG）を作れるツールです。
カードデータは [アイカツ！アンコール カードリスト](https://min-poke.github.io/cardlist-aikatsu-encore/) の `cards.js` をそのまま使用しています。

## 開き方

`index.html` をブラウザでダブルクリックして開くだけです。ネット接続が必要です（カード画像と画像生成ライブラリ html2canvas を外部から読み込むため）。

## 使い方

画面上部のタブで「所持管理」「交換」の2モードを切り替えます。モードごとにカードへの操作が変わり、1枚のカードに操作が混在しないようになっています。

### 所持管理モード

- カードごとに所持枚数（0／1／2／3+）を記録できます。未所持（0枚）のカードは画像が薄くグレーに表示されます。
- 管理状態フィルタで「所持」「未所持」に絞り込めます。

### 交換モード

- カードごとの「求」「譲」ボタンで状態を切り替えます（排他、もう一度押すと解除）。状態のあるカードには枚数（＋／−）を指定できます。
- 「予定」ボタンは「求」または「譲」を選んだカードにだけ有効になるトグルで、交換相手が決まったカードに重ねて付けます。求＋予定は「もらう予定」、譲＋予定は「あげる予定」として表示されます（独立した3つ目の状態ではありません）。
- 管理状態フィルタは「求」「譲」「もらう予定」「あげる予定」から絞り込めます。
- カード下部には現在の所持枚数が読み取り専用の小さな表示で添えられます（操作はできません。所持枚数の変更は所持管理モードで行います）。

### 共通

- 弾・レアリティ・パラレル表示・検索は両モード共通で併用できます。レアリティは PR→ER→R→N の順で表示されます。
- 画面上部の「交換画像を作成」ボタンを押すと、「譲」が上・「求」が下に分かれたレイアウトの画像が1枚のPNGとしてダウンロードされます（もらう予定／あげる予定のカードと所持枚数は、交換が成立済みのため画像に含まれません）。
- 選択内容・所持枚数はブラウザに保存され、リロードしても消えません。「選択をすべてクリア」ボタンは誤操作防止のため、2回押すと確定します（所持枚数はクリアされません）。

## 注意

- 画像生成には [html2canvas](https://html2canvas.hertzen.com/)（CDN読み込み）を使用しています。オフライン環境では画像生成ができません。
- 共有URL機能はこのツールにはありません。
